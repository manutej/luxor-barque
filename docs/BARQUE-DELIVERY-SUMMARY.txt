🎨 THEME SPECIFICATIONS

Light Theme:
  • Background: #ffffff (white)
  • Text: #1a1a1a (dark gray)
  • Accent: #2563eb (blue)
  • Use for: Printing, bright environments
  • Location: PDFs/light/

Dark Theme:
  • Background: #1a1a1a (dark gray)
  • Text: #e8e8e8 (light gray)
  • Accent: #60a5fa (light blue)
  • Use for: Screen reading, eye strain prevention
  • Location: PDFs/dark/

Processing Times:

❓ TROUBLESHOOTING

  brew install pandoc

No wkhtmltopdf?
  brew install wkhtmltopdf

PDFs not generating?
  tail PDFs/generation.log

Theme colors missing?
  rm PDFs/.temp/*-theme.css && ./pdf-orchestrator.sh priority
